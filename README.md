# 硅基流动 · 发票自助开票改版高保真原型

发票开具页面的改版交互原型，覆盖 5 条需求。单文件纯静态页面，无外部依赖。

## 在线预览

GitHub Pages 部署后访问仓库 Pages 地址即可。

## 需求与实现对照

| # | 需求 | 原型实现 |
|---|---|---|
| 1 | 线上自助开票规则放开 | 规则引擎按 `认证身份 × 金额 × 发票类型` 三轴实时切换提交语义 |
| 2 | 自助作废 | 仅「自助申请 + 已开票」可作废；作废后金额退回可开票额度 |
| 3 | 子项目名称带站点标识 | 固定「生产生活服务」+ 三个带站点后缀子项，默认 `模型API调用(siliconflow.cn)` |
| 4 | 下载格式放开 | 默认打包 ZIP（PDF + OFD + XML），`▾` 可选单格式 |
| 5 | 发票备注收集 | 选填 textarea，200 字上限，透传至开票备注栏 |

## 自助开票资格矩阵

| 认证身份 | 发票类型 | 单张金额 | 提交按钮 | 处理方式 |
|---|---|---|---|---|
| 个人认证 | 增值税普通发票 · **企业抬头** | ≤ ¥5,000 | 申请发票 | **线上自助（本次放开）**，不限张数 |
| 个人认证 | 增值税普通发票 · 企业抬头 | > ¥5,000 | 提交特殊开票申请 | 财务审核后人工开具 |
| 个人认证 | 增值税普通发票 · 个人抬头 | ≤ ¥5,000 | 申请发票 | 沿用现状能力 |
| 个人认证 | 增值税专用发票 | 任意 | 前往表单申请 | 表单申请 + 人工开具 |
| 企业认证 | 增值税普通发票 | ≤ ¥5,000 | 申请发票 | 线上自助 |
| 企业认证 | 增值税专用发票 | 任意 | 前往表单申请 | 表单申请 + 人工开具 |

企业认证账号的抬头与税号锁定为已认证主体，不可编辑。

个人认证下，抬头类型为显式二选一（企业抬头 / 个人抬头），**默认选中「企业抬头」**——这是本次需求的核心新增能力，因此放在默认位置，并带「本次新增」角标；个人抬头标注「现状」，明确本次未作调整。选择企业抬头时，抬头名称与纳税人识别号均为必填，未填满则提交按钮置灰。

## 演示方式

申请抽屉内「抬头名称和税号」区域可直接切换「企业抬头 / 个人抬头」，用于演示本次新增能力与现状能力的差异。

页面顶栏右上角与申请抽屉内各有一个「演示身份」切换器，两处状态双向同步。切换后可看到个人认证与企业认证的字段差异、抬头可编辑性与拦截提示变化。

金额输入框下方提供 `0.42 / 4,999 / 5,000 / 5,001 / 12,000` 快捷值，用于快速演示限额边界行为（5000 与 5001 的按钮语义完全不同）。

## 待确认事项

1. 页面顶部现有说明「发票抬头需与实名认证主体名称一致」与本次放开规则冲突，需法务/财务确认措辞。
2. 作废与红冲的边界：客户已入账或已抵扣时应走红字发票冲销，当前原型仅有「确认作废」单一路径，如财务规则涉及时效分界需补充分支。
