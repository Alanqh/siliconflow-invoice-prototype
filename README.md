# 硅基流动 · 发票自助开票改版高保真原型

发票开具页面的改版交互原型，覆盖 5 条需求。单文件纯静态页面，无外部依赖。

## 在线预览

GitHub Pages 部署后访问仓库 Pages 地址即可。

## 需求与实现对照

| # | 需求 | 原型实现 |
|---|---|---|
| 1 | 线上自助开票规则放开 | 规则引擎按 `认证身份 × 金额 × 发票类型` 三轴实时切换提交语义 |
| 2 | 自助作废 | 仅「自助申请 + 已开票」可作废；作废后金额退回可开票额度 |
| 3 | 子项目名称带站点标识 | 固定「生产生活服务」+ 三个带站点后缀子项，默认 `模型API调用(siliconflow.cn)` |
| 4 | 下载格式放开 | 默认打包 ZIP（PDF + OFD + XML），`▾` 可选单格式 |
| 5 | 发票备注收集 | 选填 textarea，200 字上限，透传至开票备注栏 |

## 自助开票资格矩阵

| 认证身份 | 开票金额 | 可选抬头 | 提交按钮 | 处理方式 |
|---|---|---|---|---|
| 个人认证 | ≤ ¥5,000 | 个人抬头 / 历史开票抬头 / 自定义企业抬头 | 申请发票 | 线上自助，不限张数 |
| 个人认证 | > ¥5,000 | **仅个人抬头** | 提交特殊开票申请 | 财务审核后人工开具 |
| 个人认证 | 任意 | 个人 / 企业抬头 | 前往表单申请 | 专票不支持自助 |
| 企业认证 | ≤ ¥5,000 | 仅已认证企业 | 申请发票 | 线上自助 |
| 企业认证 | > ¥5,000 | 仅已认证企业 | 提交特殊开票申请 | 财务审核后人工开具 |

## 抬头选择逻辑

个人认证下，抬头为下拉选择，不要求用户从头手工填写：

- **个人抬头** —— 始终可选
- **历史开票抬头** —— 过去成功开票过的企业抬头，仅金额 ≤ ¥5,000 时出现在下拉中
- **自定义企业抬头** —— 仅金额 ≤ ¥5,000 时可选；选中后才展开企业名称与纳税人识别号输入框，两项均必填

下拉本身承载抬头名称，因此不重复展示名称：

- 选中**个人抬头**或**历史开票抬头**时，下方只展示一个「纳税人识别号」字段
- 选中**自定义企业抬头**时，下方展开「企业名称」与「纳税人识别号」两个输入框，替代税号展示块

金额超过 ¥5,000 时，下拉中只保留个人抬头，历史抬头与自定义入口自动隐藏，避免用户在超限场景下选了企业抬头后被后端驳回。

## 发票类型

个人认证固定为**增值税普通发票**，不提供类型下拉（个人开专票需走特殊开票申请表）。企业认证保留类型下拉，选专票时按钮变为「前往表单申请」。

## 开票金额

不提供快捷金额按钮——应开金额只有用户自己清楚，系统无法给出合理推荐值。输入框默认留空，未填时提交按钮置灰。

## 发票备注

位于「开票信息」区块内，为开票信息的组成部分。标注「非必要不填写」，并提示所填内容原样写入备注栏、开票后不可修改、因备注有误产生的重开或退票成本由用户承担。

企业认证账号的抬头锁定为已认证主体，不可编辑，不出现下拉。

## 演示方式

申请抽屉内「抬头名称和税号」区域可直接切换「企业抬头 / 个人抬头」，用于演示本次新增能力与现状能力的差异。

页面顶栏右上角与申请抽屉内各有一个「演示身份」切换器，两处状态双向同步。切换后可看到个人认证与企业认证的字段差异、抬头可编辑性与拦截提示变化。

金额输入框下方提供 `0.42 / 4,999 / 5,000 / 5,001 / 12,000` 快捷值，用于快速演示限额边界行为（5000 与 5001 的按钮语义完全不同）。

## 待确认事项

1. 页面顶部现有说明「发票抬头需与实名认证主体名称一致」与本次放开规则冲突，需法务/财务确认措辞。
2. 作废与红冲的边界：客户已入账或已抵扣时应走红字发票冲销，当前原型仅有「确认作废」单一路径，如财务规则涉及时效分界需补充分支。

## 技术说明

- 单 HTML 文件，原生 JS，无构建步骤
- 仅静态演示，数据为本地 mock，不涉及真实开票接口

## 操作时段限制

自助开票与自助作废均受操作时段约束：**工作日 10:00–19:00**。

- 非操作时段，「申请发票」按钮置灰，悬浮提示当前不在操作时段
- 非操作时段，可作废的行其作废按钮置灰，悬浮提示原因
- 抽屉内的提交按钮同步禁用，页脚给出说明

顶部提供「操作时段」演示切换器，可在 10:00–19:00 与非操作时段之间切换，便于查看两种状态。

## 作废按钮显隐规则

只有**自助申请 + 已开票**的发票才出现作废按钮：

| 记录类型 | 作废按钮 |
|---|---|
| 自助申请 · 已开票 | 显示（红色），操作时段内可点 |
| 自助申请 · 开票中 | 不显示 |
| 自助申请 · 已作废 | 不显示 |
| 人工开具 · 任意状态 | 不显示 |
